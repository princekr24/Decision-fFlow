Conditional Logic Cheat Sheet
  • if: Runs code block only when condition evaluates to truthy.
  • if / else: Binary choice — exactly one block always executes.
  • else if: Evaluates sequentially; stops at first matching condition.
  • && (AND): Short-circuits to false if first operand is false.
  • || (OR): Short-circuits to true if first operand is true.
  • ? : (Ternary): condition ? ifTrue : ifFalse inline expression.

      Flowchart Shape Standards

      • Oval / Pill: Start and End of the program execution.
      • Diamond: Decision point evaluating a boolean (True / False).
      • Parallelogram: Input / Output statement (e.g. console.log).
      • Rectangle: Process step — a calculation or assignment (e.g. bill = units * 3).
      • Green Border: Condition evaluated to TRUE.
      • Rose/Red Border: Condition evaluated to FALSE.
